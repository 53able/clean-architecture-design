# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-09-15

### Added

- Initial Clean Architecture design skill and workflow.
- Templates for actor/use-case mapping, architecture diagnosis, boundary decisions, migration planning, and architecture monitoring.
- Reference guides for architecture evaluation, boundary selection, design rules, and incremental refinement.
- Dependency-direction and cycle checker with a sample boundary inventory.
- English and Japanese documentation.
